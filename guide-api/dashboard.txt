=======================================
API DASHBOARD - Dokumentasi
Base URL: http://localhost:3000
Swagger : http://localhost:3000/api
=======================================

1. AUTHENTICATION
----------------
Semua endpoint /dashboard butuh JWT (APP_GUARD JwtAuthGuard global).
Ambil token:

  POST /auth/login
  Content-Type: application/json
  { "email":"[EMAIL]", "password":"admin123" }
  Response 200: { "access_token":"eyJhbGciOi..." }

Header tiap request:
  Authorization: Bearer <access_token>
Tanpa header -> 401 Unauthorized

3. FILTER PARAMETERS
-------------------
Semua endpoint bulanan (/dashboard/penjualan-bulanan, /dashboard/pembelian-bulanan, /dashboard/profit-bulanan)
mendukung filter query parameter berikut:

a) periode (YYYY-MM)
   Contoh: ?periode=2026-08
   Filter 1 bulan spesifik.
   Prioritas tertinggi, jika ada langsung dipakai.

b) bulan + tahun (numeric)
   Contoh: ?bulan=8&tahun=2026
   ?month=8&year=2026 (alias)
   Kedua harus ada bersamaan.

c) tanggal / date (YYYY-MM-DD)
   Contoh: ?tanggal=2026-08-15
   Filter 1 hari spesifik.

d) startDate + endDate (YYYY-MM-DD)
   Contoh: ?startDate=2026-01-01&endDate=2026-08-31
   Filter range tanggal.
   Validasi: startDate tidak boleh > endDate.

e) tahun / year (numeric saja)
   Contoh: ?tahun=2026
   Filter semua data di tahun tersebut.


4. VALIDATION
-------------
- Global ValidationPipe whitelist:true transform:true
- Semua filter opsional, tanpa filter = semua data
- tanggal/date/startDate/endDate: @IsDateString (format YYYY-MM-DD)
- bulan/month: @IsInt @Min(1) @Max(12)
- tahun/year: @IsInt @Min(2000) @Max(2100)
- periode: @IsString pattern YYYY-MM (validasi di service)
- Error 400 jika format invalid.


5. POWER SHELL
--------------
$login = Invoke-RestMethod -Uri http://localhost:3000/auth/login -Method Post -ContentType "application/json" -Body '{"email":"[EMAIL]","password":"admin123"}'
$token = $login.access_token; $headers = @{ Authorization = "Bearer $token" }

# dashboard summary
Invoke-RestMethod -Uri http://localhost:3000/dashboard -Headers $headers

# penjualan bulanan - semua
Invoke-RestMethod -Uri http://localhost:3000/dashboard/penjualan-bulanan -Headers $headers

# penjualan bulanan - filter periode
Invoke-RestMethod -Uri "http://localhost:3000/dashboard/penjualan-bulanan?periode=2026-08" -Headers $headers

# pembelian bulanan - filter range
Invoke-RestMethod -Uri "http://localhost:3000/dashboard/pembelian-bulanan?startDate=2026-01-01&endDate=2026-06-30" -Headers $headers

# profit bulanan - filter tahun
Invoke-RestMethod -Uri "http://localhost:3000/dashboard/profit-bulanan?tahun=2026" -Headers $headers

7. CATATAN
----------
- Tidak ada POST, PATCH, DELETE - read only
- Semua data dari view SQL (view_dashboard, view_dashboard_penjualan_bulanan, view_dashboard_pembelian_bulanan, view_dashboard_profit_bulanan)
- Swagger grouping "dashboard" dengan lock icon, perlu Authorize Bearer token
- Field Decimal/Int dikembalikan sebagai number (bukan string) untuk view bulanan
- view_dashboard field Decimal dikembalikan sebagai string (Prisma behavior)
- Empty response = 200 array [] atau object zero-filled, bukan 404
